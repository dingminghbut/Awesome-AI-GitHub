## 为什么做这个

AI + 电商开源变化太快，静态收藏夹很容易过期。本仓库持续整理当前值得关注的项目，保留轻量历史信号，并突出正在获得关注的开源工作，帮助商家、运营者、开发者和创业者更早发现有价值的方向。
